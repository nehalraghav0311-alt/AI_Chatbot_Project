==================== Slide 5 ====================

Tabular Data Evolution

Base data.frame
The standard, built-in 2D tabular data structure in R. It holds heterogeneous columns, meaning each column can contain a different data type (numeric, character, logical). It is often noted for its legacy behavior of automatically coercing character strings into factors when importing data.   

data.table
A high-performance package that extends the standard data frame, optimized for speed and large datasets. It operates using a concise syntax formatted as DT[i, j, by], which translates to subsetting rows i, manipulating columns j, and grouping by by. It is highly memory-efficient because it performs modifications by reference, updating data in place rather than creating new copies in memory.  
 
tibble (tidyverse)
A modern, opinionated reimagining of the data frame used within the tidyverse ecosystem. It enforces strict subsetting rules, meaning it does not do partial matching on column names and will throw an error if you try to access a column that does not exist. It also features enhanced console printing limits, displaying only the first 10 rows and the columns that fit on your screen to prevent overwhelming the console

==================== Slide 9 ====================

Informed Search: A* Algorithm
The algorithm evaluates nodes on a grid or graph by combining two cost functions. At each step, it selects the node n that minimizes the following equation: f(n) = g(n) + h(n)
n: The current node being evaluated.
g(n)(Actual Cost): The exact cost of the path taken so far from the starting node to node $n$.$h(n)$ (Heuristic Cost): An estimated cost from node $n$ to the target node.
f(n)(Total Estimated Cost): The lowest estimated total cost of a path that runs from the start to the finish, passing through node $n$.

g(n): Path Cost

Exact cost from start to node n.

h(n): Admissible Heuristic

Estimated cost to goal (e.g., Misplaced Tiles).


==================== Slide 10 ====================

Hill Climbing is a mathematical optimization algorithm and local search technique used in artificial intelligence to find a local optimum (a peak) for a given problem. Unlike A*, which maintains a search tree and remembers past states to find the guaranteed shortest path, Hill Climbing only looks at the immediate neighbors of its current state and permanently discards the rest.

It is entirely greedy—it simply looks around, picks the direction that goes "up" (improves the objective function), and moves there. It stops when it reaches a peak where no neighbor has a higher value. 

How the Algorithm Works
Hill climbing does not maintain an Open List or Closed List. It only keeps track of a single current_state.
1.Evaluate the initial_state. If it is the goal state, return it and stop.Otherwise, set it as the current_state.
2.Generate the neighbors (immediate possible moves) of the current_state.
3.Evaluate the objective function h(n) for each neighbor.
4.Find the neighbor with the highest h(n) value.
5.If this best neighbor has a lower or equal h(n) than the current_state, stop and return the current_state. (You have reached a peak).
6.Otherwise, set the current_state to this best neighbor and repeat from Step 2.

Three Major Limitations
Because Hill Climbing does not look ahead or remember where it has been, it is highly susceptible to getting stuck in sub-optimal states:

Local Maxima: A state that is better than all of its immediate neighbors, but worse than the true Global Maximum. Once the algorithm hits a local maximum, it stops, falsely believing it has found the best possible solution.

Plateaus (Flat Local Maxima): A flat area of the state-space landscape where all neighboring states have the exact same value. The algorithm loses direction because no move improves the score, causing it to wander aimlessly or stop prematurely.

Ridges: A sequence of local maxima that slowly rise toward a peak. The algorithm may oscillate tightly from side to side across the ridge, making very little forward progress.
Local Maxima

Peak higher than neighbors, but below global optimum. Requires back-propagation.

Plateaus

Flat search space evaluating to identical utility. Requires random large jumps.

Ridges

Sequence of local maxima forming an axis. Demands multidirectional movement.

Linear Regression Mechanics
The linear regression equation defines the predictive model used to establish a linear relationship between an independent variable and a dependent variable.
y = a_0 + a_1x + ε: 
y:The dependent variable (the actual target value you are trying to predict).

x: The independent variable (the input feature used to make the prediction).

a_0: The Y-intercept, representing the baseline degree of freedom (the predicted value of y when x is zero).  
 
a_1: The linear scale coefficient or slope, representing how much y is expected to change for a one-unit change in x.  
 
ε: The random error term, which accounts for the natural variance in the data that the linear model cannot explain.

Mean Squared Error (MSE)
MSE is the cost function used to evaluate how well the linear regression model performs. It quantifies the average squared differences between the model's predicted values and the actual observed values. 
  
MSE= (1/n) * sum((y_i - y_hat_i)^2): The total number of observations or data points.
y_i: The actual, observed value of the target variable for a specific data point.
hat{y}_i: The predicted value generated by the model for that same data point (calculated using the linear regression formula).
(y_i - \hat{y}_i)^2: The squared residual, representing the squared distance between the prediction and the truth. Squaring ensures negative and positive errors do not cancel out and heavily penalizes larger errors.

Σ: The summation symbol, indicating that you add up the squared errors across all $n$ data points before dividing by $n$ to find the average.

Cost function quantifying average squared difference between predicted and actual values.

==================== Slide 19 ====================

Classification Topologies

Support Vector Machine (SVM)
How it Works:
SVM is a model that categorizes data by finding the optimal dividing line or hyperplane between different classes. It operates by achieving "Maximum margin boundary separation via Kernel tricks." The algorithm identifies the specific data points closest to the opposing class—known as support vectors—and calculates a boundary that maximizes the empty space (margin) between these points. If the data cannot be separated by a straight line, SVM applies a "kernel trick," a mathematical function that maps the data into a higher-dimensional space where a linear separation becomes possible.   
How its Graph Works: 
A standard SVM graph is a scatter plot showing data points plotted in a feature space. The most prominent element is the solid line (or plane in 3D) separating the different colored data points, representing the decision boundary. Parallel to this boundary, you will typically see two dashed lines running exactly through the support vectors; the gap between these dashed lines represents the optimized margin.

Naïve Bayes 
How it Works: 
This algorithm uses Bayes' Theorem to classify data based on the calculated probability that a given data point belongs to a particular category. It generates a "Probabilistic prediction assuming strict feature independence." The model is considered "naïve" because it assumes that every feature is completely independent of the others—meaning the presence of one feature does not affect the probability of another. It calculates the final classification by multiplying the individual probabilities of all observed features.  
How its Graph Works:
Naïve Bayes is often visualized using a probability density graph, which looks like overlapping bell curves (Gaussian distributions). The graph plots the likelihood of a data point belonging to a class across a continuous feature axis. The decision boundary is established precisely where the probability curves of two competing classes intersect, marking the exact threshold where a point becomes mathematically more likely to belong to the other class.

Decision Trees
How it Works:
A decision tree classifies data by breaking it down into smaller subsets using a sequence of simple rules. It structures these rules through "Entropy and Gini-impurity driven nodal splits." At every step, the algorithm evaluates all available features and chooses the one that best separates the data into uniform classes. It measures this separation quality using metrics like Gini-impurity or Entropy. The data is recursively split until it reaches a final classification.   

How its Graph Works: 
Structurally, the graph is drawn as an inverted flowchart. It starts with a single "root node" at the top, branches downward through "decision nodes" (where features are tested, e.g., $x > 10$), and terminates at "leaf nodes," which represent the final class label. If you plot a decision tree's actual decision boundaries on a scatter plot, the graph features highly distinct, orthogonal (axis-parallel) box-like shapes that carve the data space into rectangles.


Random Forest
How it Works:
Random Forest is an ensemble learning algorithm built to improve the reliability of standard decision trees. It operates via "Ensemble decision aggregation mitigating single-tree overfitting." Because a single deep decision tree often memorizes noise in the training data (overfitting), a Random Forest builds multiple distinct decision trees. It does this by training each tree on a random, bootstrapped sample of the data and a random subset of features. When making a new prediction, all the trees output a classification, and the algorithm takes a majority vote to determine the final answer.  
 
How its Graph Works: 
Structurally, a Random Forest diagram displays dozens or hundreds of parallel decision trees that all feed their individual outputs into a final "aggregation" or "majority vote" node. When viewing its decision boundary on a feature space scatter plot, the graph looks like a smoothed, highly averaged version of a single decision tree. Instead of rigid, blocky rectangles, the boundary is heavily stepped and generalized, successfully ignoring outlier data points that a single tree would have drawn a box around.
